# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, focus on evidence, and keep technical disagreements about the work. Harassment or discrimination of any kind is not tolerated. Reports go to the maintainers via GitHub private reporting or the contact listed on the organisation profile; reports are handled confidentially.
